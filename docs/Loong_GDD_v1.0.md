# Loong — 游戏设计文档（GDD 1.0）

> **项目代号：** Loong / Legend-Loong  
> **文档日期：** 2026 年 10 月 14 日  
> **文档定位：** 第 1～20 轮游戏设计讨论的统一定稿基线；用于拆分 UE5 开发任务，不表示所有功能已经实现。  
> **技术基础：** Unreal Engine 5（现有项目为 UE 5.8.3），C++ 核心逻辑 + 蓝图/数据资产进行内容配置。  
> **目标形态：** 单人优先的 PC 动作肉鸽与龙族培育游戏；Steam 为拟定发行渠道，最终发行范围待确认。

## 阅读约定

- **已确定（设计决定）**：GDD 1.0 暂时锁定的产品方向，除非试玩或技术验证表明存在明显问题，否则不反复推翻。
- **待验证（设计假设）**：时长、概率、数值、难度、动画手感及具体实现形式，以原型数据为准。
- **P0**：证明核心玩法闭环的最小可玩原型；**P1**：能够稳定重复游玩的基础版本；**P2**：规划中的完整内容版本。
- **S / A / B / C / D**：S＝可重复核心系统；A＝可选、可重复的支线系统；B＝罕见世界奇遇；C＝一次性或极稀有彩蛋；D＝暂缓/储备。被明确否决的提案不属于 D。

# 1. 游戏概述与产品定位

## 1.1 一句话定位

**Loong 是一款以龙族血脉培育为长期驱动力、以人龙同行与骑乘战斗为即时体验、以肉鸽冒险为主要游玩内容的单人游戏。**

玩家作为守龙者，在基地繁殖、孵化、培养和收藏龙族；进入冒险后与主力龙并肩战斗，或骑乘并直接操控自己培育的龙。龙的物种、遗传词条、元素血脉与进化路线，都会改变实际战斗方式。玩家在一局局冒险中获得资源与线索，最终追寻远古祖脉与真正的祖龙返祖。

## 1.2 产品支柱与优先级

| 层级 | 游戏支柱 | 负责解决的问题 |
|---|---|---|
| 第一支柱 | **龙族融合、跨代遗传、进化与返祖** | 为什么开始玩、为什么持续培育 |
| 第二支柱 | **人龙同行、骑乘主控、肉鸽 Build** | 玩家大部分时间在做什么，战斗为何有趣 |
| 第三支柱 | **自由建造的龙族基地** | 永久资产、培育操作、展示个体与家族历史 |
| 调味层 | **元素生态、世界奇遇、特殊支线、彩蛋** | 偶然性、发现感、值得分享的故事 |

**不采取“三套同等重量核心”的开发方式。** 世界奇遇应服务于已有系统，不能迫使项目同时成为大型开放世界、完整生态模拟器和深度经营游戏。

## 1.3 玩家承诺

1. **我孵出的龙真的不一样。** 不仅颜色不同，遗传还能改变冲刺、弹射、喷吐、元素配合等战斗行为。
2. **我能亲自体验自己培育的龙。** 守龙者和龙共同出现在战场；骑乘时玩家直接控制龙；无法骑乘的小型成年龙保留以后实现直接操控的方案。
3. **每局都值得重新尝试。** 永久龙族遗传与局内随机 Build 相互强化，而不是互相替代。
4. **世界有少量可发现的秘密。** 罕见事件能够制造记忆点，但不强制进入主线。
5. **经营不拖慢冒险。** 基地管理便利、可跳过冗长演出，没有强制劳动流水线。

## 1.4 主要排除项

不以大型无缝开放世界、多人联机、全自动生产链、永久死亡损失珍贵龙、任意身体部件自由拼接、无限元素种类、随机生成所有古龙地牢等作为首版必备内容。

已明确否决、不得以改名形式重新引入的提案：**“基地是技能编辑器”“把敌人的弱点拔出来贴到另一个敌人身上”“偷走 BOSS 的施法时间”**。

# 2. 双层核心循环与玩家体验

## 2.1 跨局长期循环

```text
选择与培养出战龙
      ↓
携龙进入肉鸽冒险（并肩 / 骑乘）
      ↓
战斗、选择局内强化、挑战首领
      ↓
获得资源 / 纯系龙蛋 / 血脉素材 / 祖脉线索
      ↓
返回基地：繁殖、孵化、升级设施、查看家谱
      ↓
诞生拥有新基因/词条/外观/潜力的后代
      ↓
以新龙体验不同打法，寻找下一步培育目标
      ↺
```

这个循环的成功标志不是“玩家完成一次任务”，而是**玩家自发想再次尝试一种配对或构筑**。

## 2.2 单局冒险循环

```text
基地选择出战龙 / 检查成长状态
     ↓
阶段一：基础战斗、选择局内升级
     ↓
分支选择一：资源 / 精英 / 奇遇
     ↓
阶段二：强化战斗、Build 开始成形
     ↓
分支选择二：补 Build / 风险挑战 / 特殊奖励
     ↓
阶段三：高强度战斗、构筑基本成形
     ↓
终点 BOSS
     ↓
胜利结算 / 安全撤退 / 失败结算 → 基地
```

**标准局长目标：20～25 分钟（待测试）**。P0 可以先采用明显更短的测试循环，不能为了凑局长强行拉长敌人血量和生成时间。

## 2.3 玩家阶段目标

| 成长阶段 | 玩家理解/拥有的能力 | 典型目标 |
|---|---|---|
| I 萌芽 | 初始龙、并肩/骑乘、基础肉鸽 | 获得并使用第一条融合龙 |
| II 探索 | 四元素来源、基础繁殖 | 收集喜欢的物种、尝试不同元素 |
| III 培育 | 四词条、潜在血脉、家谱 | 定向培育理想家系与战斗构筑 |
| IV 觉醒 | 祖印线索、觉醒挑战 | 培育携印后代、完成远古觉醒 |
| V 祖龙 | 双祖印、祖龙试炼 | 完成真正返祖，挑战高阶内容 |

玩家不必集齐十种龙，才有资格研究某个特别喜欢的家系。

# 3. 玩家、龙与控制权

## 3.1 确定的设计：人龙同行，龙是主战力

**基地**：守龙者为可操控人物，可以自由建造、接触龙与使用设施。  
**并肩作战**：操控守龙者移动和闪避，主力龙跟随、自动基础攻击；玩家指定目标并指挥龙释放主要技能。  
**骑乘作战**：守龙者可见地骑在龙背上，玩家直接控制龙移动、冲刺、攻击、技能；龙的跟随 AI 暂停。  
**小型成年龙**：通常不骑乘。保留“直接控制小龙、守龙者自动跟随”的后续方案，不让小龙的战斗能力永久失去主动体验机会。

骑乘不应只是镜头变化或自动攻击加成。**操控对象和攻击行为必须真实改变。**

## 3.2 两种主战模式的边界

| 维度 | 并肩模式 | 骑乘模式 |
|---|---|---|
| 当前主控 | 守龙者 | 主力龙 |
| 龙的普通攻击 | 自动基础攻击 | 玩家主动触发 |
| 龙的主要技能 | 玩家发出指令 | 玩家直接瞄准、释放 |
| 主要优势 | 探索、交互、标记目标、保持安全距离 | 主动输出、机动、精确操控龙 |
| 主要风险 | 需要跟随 AI 与指令响应可靠 | 骑乘、碰撞、摄像机和体型兼容 |
| Build | 使用同一套龙的能力 | 使用同一套龙的能力 |

任何普通 BOSS 都应能用这两种模式通关；不得设置普遍性的“必须上龙才能造成伤害”或“必须下龙才能躲某招”。特殊支线可做少量例外。

## 3.3 控制与镜头

以现有俯视/斜俯视、WASD、鼠标操作、滚轮缩放和平滑镜头为基础。

| 输入 | 并肩 | 骑乘 | 基地 |
|---|---|---|---|
| WASD | 守龙者移动 | 龙移动 | 守龙者移动 |
| 鼠标 | 瞄准/指定龙的目标 | 龙攻击方向 | 建造指向/选择 |
| 左键 | 标记目标/普通指令 | 普通攻击 | 建造确认/界面选择 |
| 右键 | 备用指令或瞄准（待手感验证） | 蓄力或重击 | 上下文操作 |
| Shift | 守龙者闪避 | 龙冲刺/闪避 | 可选加速 |
| 1 / 2 / 3 | 指挥龙的元素技能 | 主动释放相同能力 | — |
| F | 邻近时骑乘 | 下龙 | 使用设施 |
| Tab | 冒险信息/龙资料 | 冒险信息/龙资料 | 龙族管理 |
| Esc | 暂停/返回 | 暂停/返回 | 关闭界面 |

F 的上下文交互必须有明确提示与优先级，避免在建筑旁误骑乘。保留自定义键位设计空间。键位为默认建议，非最终锁定。

## 3.4 坐骑体型与生命机制

- 轻型、标准、重型三种**战斗碰撞规格**，不将每个外观的鳞片全部纳入受击判定。
- 巨型祖龙允许在普通关卡使用受控战斗体型，巨大化可通过特殊技能或场景表现。
- P0 采用**统一的队伍生存生命条**来减少双角色管理与 UI 负担，受击对象按当前状态进行规则映射；独立血量留作后续验证。
- 骑乘状态切换须保证输入唯一归属、骑手挂点稳定、镜头平滑、跟随 AI 正确暂停/恢复。
- 飞行以地面移动、冲刺、短浮空为先；六自由度三维自由飞行不属于 P0/P1 必备。

# 4. 战斗基础、元素与十种龙的战斗身份

## 4.1 通用动作框架

所有可战斗成年龙基于统一能力框架：**普通攻击 / 强力攻击 / 机动闪避 / 元素技能 / 招牌技能**。底层命中、冷却、状态与效果通用；释放形态、节奏和联动由物种、遗传与局内强化决定。

## 4.2 四元素基础机制

| 元素 | 主要机制 | 玩法身份 |
|---|---|---|
| 火 | 燃烧、持续伤害、燃烧地面 | 持续压制和区域覆盖 |
| 冰 | 减速、寒霜积累、冻结、破碎 | 控制、时机和反击 |
| 风 | 风刃、牵引、冲刺、区域移动 | 机动、聚怪、空间操纵 |
| 雷 | 感电、连锁、蓄能与爆发 | 目标选择、连锁、爆发节奏 |

火、冰、风已有逻辑基础，但曾出现**实际战斗中效果不明显/看不到**的问题；必须先进行可见性和有效性验收。雷元素为后续实现内容，不应假设已完成。

## 4.3 十种基础与融合物种

| 类别 | 物种 | 显性元素 | 招牌战斗循环 |
|---|---|---|---|
| 纯系 | 火龙 | 火 | 喷吐覆盖 → 燃烧压制 |
| 纯系 | 冰龙 | 冰 | 积累寒霜 → 冻结/碎裂 |
| 纯系 | 风龙 | 风 | 高速移动 → 牵引/风刃 |
| 纯系 | 雷龙 | 雷 | 施加感电 → 连锁/爆发 |
| 融合 | **风暴龙** | 风+雷 | 牵引聚怪 → 感电连锁 |
| 融合 | **冰焰龙** | 火+冰 | 冷热交替 → 温差失衡 |
| 融合 | **烈风龙** | 火+风 | 燃烧覆盖 → 风场扩散/冲刺留火 |
| 融合 | **雷焰龙** | 火+雷 | 雷火标记 → 主动选择过载时机 |
| 融合 | **霜翼龙** | 冰+风 | 寒风控制 → 冻结与路线封锁 |
| 融合 | **霜雷龙** | 冰+雷 | 冰晶导电 → 传导/反击 |

**不设计三元素或四元素的新普通物种。** 第三、第四元素允许以潜在基因存在，但不会直接赠送它们的完整技能组。后期古龙是另立图鉴的固定物种，属于明确例外。

注意：融合不应普遍退化成“叠两个元素就爆炸”。各物种必须体现不同决策方式：位置、节奏、扩散、连锁或传导。

## 4.4 技能效果模块化

统一四层：

1. **攻击形态**：弹丸、喷吐、近战、冲刺、范围领域。
2. **元素效果**：燃烧、寒霜、牵引、感电。
3. **行为修饰**：分裂、穿透、弹射、追踪、留痕、延迟触发。
4. **触发条件**：命中、击杀、状态累积、冲刺结束、技能交替。

示例：雷电弹丸 + 弹射＝连锁雷弹；冲刺 + 火 + 留痕＝烈焰轨迹。

模块化用于复用生产，不意味着所有元素与效果都向玩家无条件开放。**物种确定可用机制，血脉词条改变部分行为，肉鸽升级临时强化。** 对追加弹丸、分裂深度、弹射次数、递归触发设置统一上限和性能预算。

# 5. 肉鸽 Build 与技能进化

## 5.1 永久与临时能力分层

| 层级 | 内容 | 结算后 |
|---|---|---|
| 物种/遗传 | 物种技能、元素血脉、四遗传词条、外观变异、祖印 | 保留 |
| 永久成长 | 等级、战斗专精、觉醒、个人经历 | 保留，不自动遗传 |
| 局内 Build | 升级三选一、临时装备/强化、局内技能进化 | 清除 |

**遗传决定可玩的方向，局内随机决定当局如何发挥。** 普通龙能组成有效 Build；珍贵血脉带来不同玩法入口，而非简单的必胜高倍率。

## 5.2 升级奖励四类

- **基础强化**：多一道风刃、扩大攻击范围等。
- **攻击行为变化**：命中分裂、冲刺留火、技能回旋等。
- **元素协同**：风场扩散火焰、冰晶形成导电网络等。
- **风格取舍**：更强爆发伴随过热、降低防御、增加技能准备动作等。

每次三选一须**至少有一个即时可用选项**；另外尽量提供当前 Build 的协同选项和一次转型机会。允许有限重选。不要让玩家因候选全与当前物种无关而失去本局体验。

## 5.3 物种 Build 示例

| 物种 | 路线 A | 路线 B |
|---|---|---|
| 火龙 | 持续喷火 | 地面燃烧 |
| 冰龙 | 冻结控制 | 冰晶碎裂 |
| 风龙 | 高速冲刺 | 风刃牵引 |
| 雷龙 | 连锁闪电 | 蓄能爆发 |
| 风暴龙 | 雷暴连锁 | 风雷机动 |
| 冰焰龙 | 温差爆发 | 冷热领域 |
| 烈风龙 | 燃烧扩散 | 烈焰冲刺 |
| 雷焰龙 | 雷火过载 | 持续灼雷 |
| 霜翼龙 | 寒风封锁 | 冰翼机动 |
| 霜雷龙 | 冰晶导电 | 霜雷反击 |

这些是构筑方向，不等于需要 20 套完全独立的动画和技能代码。

## 5.4 局内技能进化

条件：**已有物种基础能力 + 相关局内强化组合 + 一次明确的进化选择**。例如烈风龙“燃烧风刃 + 余烬残留 + 疾风扩散”可选择进化为临时技能“烈焰风暴”。

必须在 UI 中解释路线和基本前置条件；稀有隐藏进化可以作为彩蛋，但不能成为正常 Build 唯一的必要知识。**局内进化不改写蛋的基因，不等于远古觉醒，更不等于真正返祖。**

## 5.5 并肩/骑乘兼容

同一 Build 在两种模式下均生效，释放方式可不同。示例：“冲刺留火”骑乘时由玩家冲刺触发；并肩时由龙的指令冲刺触发。避免为两种控制模式分别维护完全独立的升级池。

# 6. 敌人、BOSS 与元素生态

## 6.1 敌人职责设计

| 敌人行为类型 | 主要压力 |
|---|---|
| 追击怪 | 贴近、压缩空间 |
| 疾行怪 | 突进与闪避时机 |
| 远程怪 | 弹丸、改变优先攻击目标 |
| 重甲怪 | 正面防御、破绽窗口 |
| 聚集/辅助怪 | 击杀顺序与敌人协同 |
| 干扰怪 | 危险区、路线限制 |
| 吞核怪 | 吞食元素核心后的战斗变化 |
| 猎龙怪 | 针对骑乘、移动方式的可读招式 |

**敌人类型是行为标签，未必要 8 套完整美术。** 优先使用已有追击、快速与紫色远程怪，并增加少量机制型精英。随机刷怪应采用压力预算，避免高远程、高突进和大范围危险同时失控。

## 6.2 精英设计

- **裂甲守卫**：正面防御，攻击后露出破绽。
- **元素吸收者**：连续受单元素攻击后暂时适应，形成软克制，不完全免疫。
- **噬核兽**：寻找战场元素残留核心并吞食，获得变异技能。

## 6.3 战场元素残留核心

部分敌人死亡后会产生短暂存在的**战场元素残留核心**（与带回基地的永久血脉材料/祖脉遗物**不是同一资源**）。它可被特定敌人吞食，影响当场战斗。风推、冰冻暂停、火触发等进一步交互属于**待验证的生态扩展**，先实现一种元素与一种吞核怪。

玩家能阻止吞食，也能主动放任变异来挑战更高风险。**不强制每波都刷吞核怪，不把生态模拟拓展到全世界所有怪物。**

## 6.4 BOSS 设计原则

普通 BOSS 至少具备：一个可辨认主题、清晰预警、可学会的基础招式、一个阶段变化。避免纯堆血量、全面元素免疫、只允许特定龙通关。

首个较完整的概念 BOSS：**雷核吞噬者**。

1. 第一阶段：爪击、地面雷纹、蓄力吐息，训练躲避。
2. 第二阶段：召唤元素小怪；死亡后出现短暂核心；首领尝试吸收，玩家可阻止或允许。
3. 第三阶段：将已学过的招式与已吸收核心带来的有限环境效果组合。

允许 BOSS 吸收是玩家可理解、可主动选择的风险，而不是看不见的随机惩罚。

## 6.5 玩家培养 BOSS（A 类支线）

**灾厄培育场**：玩家向特殊胚胎投入元素核心、战斗词条，主动提高 BOSS 强度并挑战，以换取设有上限的风险奖励。**不进入 P0，不是主线必须玩法**；不得让玩家培育出打不过的 BOSS 后永久阻塞主线。

## 6.6 战斗可读性

危险预警 > 攻击命中与元素反馈 > 华丽视觉。玩家培养出高阶风雷龙之后，也必须看得见敌人弹丸与危险地面提示。提供降低特效强度、减少伤害数字密度等选项。

# 7. 龙种与遗传数据模型

## 7.1 物种与个体分离

**DragonSpeciesDefinition（物种静态定义）**包含：物种 ID、显性元素组合、基础战斗定位、通用动作组、可用技能池、基础外观、进化分支、适用体型和骑乘兼容性。  
**DragonInstance（个体持久数据）**包含：唯一 ID、物种 ID、元素血脉、潜在元素、遗传词条（至多四个）、外观/体型变异、父母 ID、祖脉印记、年龄阶段、成长、进化/觉醒、个人经历和收藏/锁定状态。

名称允许重复，系统身份只认唯一 ID。战斗出场形态由物种静态数据 + 个体遗传 + 永久成长 + 临时 Build 组合形成。

## 7.2 元素血脉比例

每个个体记录火/冰/风/雷四个非负血脉分量，**总和恒为 100%**。

- 后代基础比例围绕两位亲代的血脉比例均值重组，再施加有限、可控的小幅波动。
- 两位亲代都不携带的元素，不会仅凭普通比例浮动突然出现。
- 根据权重前两位显性元素及**第二显性阈值**判定固定物种；不足阈值时表现为第一主元素纯系。
- 低占比元素继续作为潜在血脉，可在之后世代重新表现，但不直接赋予完整第三元素技能。
- 比例相同或接近阈值时，按确定性规则裁定物种，不能因读档而重算。
- 初始建议用于测试的第二显性阈值为 **25%（待验证）**，不是正式平衡承诺。

示例：烈风龙（火 60%、风 40%）与雷龙（雷 100%）繁殖，后代均值可能接近火 30%、风 20%、雷 50%；在当前阈值假设下表现为**雷焰龙**，风为潜在血脉。

需在代码中处理：百分比归一化、舍入、相等权重、边界波动、未解锁物种的获取条件与图鉴记录。

## 7.3 四个遗传词条槽

最多四个先天词条，可有空位。词条类别包括：攻击行为、元素亲和、生存、机动、特殊变异。允许继承、有限变异；互斥词条不可同时生效；同一词条不能无限叠加。

示例词条：迅捷、厚重鳞甲、分裂龙息、雷电回响、冰晶破碎、风之亲和、雷暴之心、六翼、黑雷核心、雷电反噬。

不同词条不只代表品质高低，而应改变操作或形成取舍。例如“雷电反噬”带来高爆发与短暂脆弱，“巨龙化”增加覆盖但降低机动。

**遗传算法和具体概率待实验**；首版至少能清楚展示：候选词条来自哪位亲代、哪些互斥、哪些属于少量突变。不要把概率完全隐藏，造成纯抽奖式育种体验。

## 7.4 外观遗传

采用：**固定物种基础身体 + 材质/花纹/色彩变动 + 有限制的部件变异 + 体型档位**。

可继承表现：元素鳞纹、角形、尾形、翅膀数量的少数特例、袖珍化/巨龙化。所有结构变化须有对应数据标记、骨骼/骑乘挂点兼容方案；不实现身体部位任意跨物种拼接。

## 7.5 祖印与普通词条分离

祖印不是四词条之一。**每种祖脉按 0、1、2 份印记记录**：

- 0：无该血统。
- 1：携带者，可向后代传递对应祖印。
- 2：具备挑战对应真正返祖试炼的遗传资格，但不能直接自动返祖。
- 每位亲代对同一后代至多贡献**一份**对应祖印，不能由一位双印亲代单独赠送两份。
- 两亲代都没有该祖印，普通繁殖不生成该祖印。
- 至少设计两个独立可追踪的祖印来源，避免强迫玩家近亲繁殖。

后代的祖印传递概率与具体组合规则属于待平衡项；验收时必须能够稳定保留和正确追踪来源。

## 7.6 蛋数据的确定性

**确认繁殖并生成龙蛋时，立即结算完整遗传数据并存档。** 孵化仅揭晓、展示、解除成长限制。任何读档、建筑移动、冒险失败都不得导致龙蛋基因被重抽。为测试与复现错误，建议记录繁殖随机种子、亲代 ID、生成版本和生成时间。

# 8. 龙的成长、进化与返祖

| 类型 | 是否改变物种 ID | 对后代是否自动遗传 | 功能 |
|---|---|---|---|
| 成长：蛋→幼龙→成年 | 否 | 等级、年龄不遗传 | 外观成熟、完整出战与繁殖资格 |
| 常规进化/战斗专精 | 通常否 | 专精选择不直接遗传 | 物种内部技能分支，例如风暴龙的裂空/雷狱路线 |
| 远古觉醒 | 否 | 觉醒状态不遗传 | 古老形态、招牌技能强化、个体成长目标 |
| **真正返祖** | **是，进入固定古龙物种** | 子代不自动复制返祖形态；祖印按规则遗传 | 独立古龙表现与高阶战斗玩法 |

**核心示例**：风暴龙携带符合条件的双天劫祖印，成年并完成专属试炼后，可真正返祖为**太古天劫龙**。

古龙不是简单的十倍属性膨胀，应具有独特战斗机制和构筑取舍，普通龙仍能完成大部分正常冒险。

## 8.1 后天经历档案

每条龙区分三个档案：

1. **血脉档案**：元素比例、先天词条、祖印、外观基因——可按规则遗传。
2. **成长档案**：等级、专精、觉醒、个人能力——不直接遗传。
3. **经历档案**：击败特殊 BOSS、稀有孵化事件、保护龙蛋、特殊传承——通常不遗传。

“某条龙曾经打赢什么”应属于它自己的故事，不自动变成后代的免费基因。

## 8.2 孵化与成熟节奏

新手第一枚融合蛋快速孵化，成年可出战不应强制现实时间长等待。普通龙蛋支持并行积累冒险进度与批量结算；特殊孵化演出可保留给第一枚融合龙、稀有突变和祖印揭晓。允许跳过重复动画。

# 9. 基地建造、龙群管理与资源经济

## 9.1 基地定位

**龙巢谷是自由建造的龙族家园、繁殖研究中心与冒险出发点，而不是技能编辑器或强制劳动工厂。**

沿用现有 **200cm 网格**、`BaseGround` 地面射线、合法/非法颜色预览、占地/防重叠检测。建筑尺寸为 200cm 的整数倍，支持 90° 旋转、移动和安全拆除。

## 9.2 六类核心建筑

| 建筑 | 主要作用 | 建议初版占地（可调） |
|---|---|---|
| 繁殖巢 | 双亲选择、后代预览、生成蛋 | 3×3 格 |
| 孵化巢 | 龙蛋存储、并行进度、孵化 | 2×2 格 |
| 龙族栖息地 | 展示若干实体龙、待机/游荡/互动 | 4×4 格 |
| 龙族档案馆 | 搜索、筛选、家谱、锁定、亲代比较 | 3×3 格 |
| 祖脉祭坛 | 祖印研究、觉醒与返祖入口 | 4×4 格 |
| 冒险之门 | 选龙、冒险地图、挑战出发/返回 | 视模型而定 |

1×1 格装饰、道路、围栏和纪念品属于拓展层。**建筑排布不编码为隐藏的技能编辑逻辑。** 升级以容量、便利性和内容开放为主，不直接把龙的基因品质乘倍提升。

## 9.3 管理几十条/上百条龙

三个层次：**出战龙**（主力 1，后期支援 1）、**基地展示龙**（少量实例化）、**龙族档案存储龙**（数据存在，无须全部加载模型）。

档案支持：物种筛选、元素比例、词条、祖印、成长阶段、收藏锁定、重命名、双龙对比、家谱三代预览与向上追溯、批量整理。繁殖亲代从列表选择，不要求把实体搬到建筑旁。

基地实体龙的首版 AI 只需要：待机、休息、短距离游荡、对玩家简单响应。少量性格表现可以来自词条，但不需要完整模拟龙群社会关系。

## 9.4 四类经济资源

| 持久资源 | 来源 | 主要消耗 |
|---|---|---|
| 基础建材 | 普通冒险、资源路线 | 建筑、容量扩展、装饰 |
| 孵育精华 | 普通战斗、阶段结算 | 普通繁殖、孵化、幼龙成长 |
| 血脉素材 | 精英、特殊区域、奖励 | 专项培育、进化专精、血脉研究 |
| 祖脉遗物 | 遗迹、高阶 BOSS/试炼 | 觉醒、真正返祖相关步骤 |

普通繁殖不要求祖脉遗物；初始龙必须可以稳定赚取基础孵育资源，避免“没有高级龙就刷不到繁殖材料”的死锁。

可以有小规模材料回收或特殊龙的非必要产物，不制作采矿、种田、冶炼、搬运等完整生产链。基地绝不要求玩家每次出发前完成喂食与收菜任务。

## 9.5 安全规则

建筑搬迁或拆除时，其内部龙蛋与物品先进入安全存储；资源返还明确。冒险失败不会损毁基地；普通繁殖失败不永久消耗亲代。龙与龙蛋存档依赖稳定唯一 ID 和版本化数据。

# 10. 世界结构、区域与长期主线

## 10.1 世界形式

**一个永久基地 + 六个可选/逐步解锁的独立肉鸽区域**。不制作大型无缝开放世界，不需要六套不同肉鸽规则。

| 顺序/开放 | 区域 | 玩法特色 | 概念 BOSS | 关键成长 |
|---|---|---|---|---|
| 初始 | **风栖边境** | 宽地形、风场、移动与牵引 | 风巢守望者 | 基础战斗、风系 |
| 早期 | **雷鸣峡谷** | 远程弹丸、感电、元素核心 | 雷核吞噬者 | 雷龙血脉稳定来源 |
| 中期可选 | **熔火地脉** | 燃烧区域、持续危险 | 熔脊巨兽 | 火龙血脉稳定来源 |
| 中期可选 | **永冻冰原** | 冻结领域、路线封锁 | 永冬守卫 | 冰龙血脉稳定来源 |
| 后期 | **失落龙陵** | 祖先历史、混合元素机制 | 血脉守门者 | 祖印来源、祖龙线索 |
| 终局 | **天劫之眼** | 高阶元素组合、祖龙传说 | **天劫残响** | 主线结局、后续挑战 |

风栖完成早期远征后开放雷鸣；雷鸣关键挑战后开放熔火与永冻，可自主选先后；龙陵由必要的探索线索开放；天劫之眼为主线终局。

## 10.2 纯元素与融合物种来源

四纯元素（火、冰、风、雷）有可规划、相对稳定的获取途径；六种双元素融合龙**主要通过繁殖**获得。首通固定奖励可解锁基础亲代，重复挑战用于获得更合适的基因和词条。

## 10.3 主线结局与返祖边界

**玩家不必拥有太古天劫龙才能完成主线。** 主线击败天劫残响并理解祖龙历史，构成正常结局。培育双祖印风暴龙、完成天劫祖龙试炼和真正返祖，是高阶长期目标；其他祖龙家系属于后续扩展。

太古天劫祖印至少有两个独立、可追踪的来源，不把关键祖印完全藏在极低随机掉率后。

## 10.4 终局玩法

三条可独立追求的目标：**祖龙返祖**、**稀有血脉/四词条家系**、**高难度肉鸽与特殊 BOSS**。难度提高优先增加清晰的机制与敌人组合，适度数值变化，不只乘倍提高血量。

# 11. 创意分层：核心、支线、奇遇、彩蛋和否决项

不是所有有趣的点子都该成为每局必经系统。

| 层级 | 内容 | GDD 处理 |
|---|---|---|
| **S 核心** | 龙种、繁殖、遗传、成长、骑乘/并肩、局内 Build、基地、区域冒险 | 设计必须闭环 |
| **S 候选增强** | 元素死亡核心、敌人吞食变异、击杀方式影响少量掉落、个体战斗经历 | 先原型验证，不强行全面铺开 |
| **A 可选支线** | 玩家培育灾厄 BOSS、特殊天气参与孵化、借未来后代之力、返卵重生、捕获天气灾害、祖先传说重演 | 只在核心稳定后挑选；不阻主线 |
| **B 罕见奇遇** | 被放走的变异敌人回归、未选进化化为敌人、失败留下小型遗迹、弃置物被怪物带走、伤口长出后天器官、诅咒种入土地 | 小量条件触发；因果可识别 |
| **C 彩蛋** | 龙蛋内微世界、龙影独立、垃圾堆商人、技能获得意识、特殊活宝箱、龙蛋孵出世界异象、古龙归祖留下龙骨遗迹 | 不保证每位玩家遇到；可错过 |
| **D 暂缓** | 完整怪物文明模拟、所有古龙自动生成大型遗迹地牢、随意修改下一局自然法则、无限跨元素动态物种 | 不进入 GDD 1.0 必做范围 |
| **否决** | 基地是技能编辑器；转移敌人弱点；偷走 BOSS 施法时间 | 不再纳入候选 |

**“玩家过去的行为改变未来”**可作为整体叙事风格，但只记录少量关键状态，不模拟每只怪物完整生命周期。

# 12. 奖励、失败、安全撤退与存档

## 12.1 三种结算

| 结局 | 局内能力 | 永久龙族 | 持久奖励 |
|---|---|---|---|
| 击败 BOSS | 本局结束并清除 | 保留 | 本局有效战利品 + 首领奖励 |
| 安全节点撤退 | 清除 | 保留 | 保留已确认的基础奖励；失去未取得的后续目标奖励 |
| 战斗失败 | 清除 | 保留 | 带回部分基础资源；未完成的精英/BOSS 奖励不发放 |

默认**不永久失去主力龙、其基因、祖印、基地和已生成蛋**。失败代价以战利品、进度、当前机会为主。

## 12.2 关键持久数据

- 基地建筑：类型/定义 ID、网格坐标、旋转、等级、内部安全物品。
- 龙与蛋：稳定 ID、定义版本、遗传数据、亲代 ID、祖印、外观、成长/经历、状态。
- 玩家资产：资源、已发现物种、设施解锁、区域进度、祖脉线索、奖励领取标记。
- 世界事件：仅重要且可解释的持久事件标记、触发时间/次数、关联敌人/龙的 ID。
- 存档版本：用于后续数据迁移，避免新词条或新物种版本破坏旧档。

繁殖和奖励结算应避免“重复领取”“一边存档一边写入导致缺项”等问题。对于删除龙、覆盖珍贵数据、异常孵蛋结果等操作提供保护和恢复路径。

# 13. UI、HUD、易用性与新手引导

## 13.1 主界面结构

基地四个主要入口：**龙族管理 / 培育中心 / 冒险之门 / 建造模式**。

龙族详情一屏优先显示：名字、物种、元素比例、最多四词条、祖印标记、成长状态、是否收藏/出战。家谱、每个词条的来源、详细个人经历通过子页展开。支持比较两条亲代，不必来回切换多层窗口。

繁殖预览显示：双亲、可能物种、元素比例区间、可继承词条、互斥关系、祖印携带可能、资源消耗。稀有隐藏事件可以保留未知感，但**基础遗传规则不故弄玄虚**。

## 13.2 战斗 HUD

常驻：当前龙/模式、统一生命条、3 个主要技能与冷却、阶段/BOSS 进度、危险预警、必要的局内提示。后期羁绊能量可加独立小组件。基因家谱不在战斗中常驻。

所有元素技能须区分“已触发机制”与“纯装饰光效”。特效不能遮挡紫色远程弹丸或 BOSS 红圈。色彩之外还要有形状、图标、音效等辅助反馈。

## 13.3 新手六步

1. 守龙者与初始风龙同行，体验骑乘、移动、闪避、基础技能。
2. 完成首次短冒险，获得资源与一次局内升级。
3. 进入龙巢谷，使用基础孵化/繁殖设施。
4. 通过稳定的新手奖励获得雷龙；风 + 雷培育第一枚风暴龙蛋。
5. 完成快速孵化，带风暴龙战斗，明确看到风雷融合能力。
6. 通过词条差异引导玩家自行选择下一次繁殖或其他元素路线。

**新手版正式内容用风雷展示，开发中的 P0 验证先用已具备元素基础的火风→烈风龙。** 两者是不同阶段的内容选择，不是互相冲突的双版本规则。

重要目标：玩家应很早就知道“龙能繁殖，后代可以亲自骑着打，而且打法真的不同”。不强制连续数十分钟建造/采集教程。

# 15. UE5 技术落地建议（非现有实现声明）

## 15.1 当前项目基础（来自开发过程反馈）

- 已有 `L_Combat` 战斗地图、GameMode 与关卡 Director/Definition 配置思路。
- 有 C++ 战斗框架与 Blueprint 内容搭配的开发方向，具有多敌人、阶段、远程弹丸、局内升级暂停与结算基础。
- 紫色远程怪弹丸可见且能够躲避；火、冰、风曾出现**视觉/表现未通过验收**的情况，需排查。
- 基地已有 200cm 网格建筑预览、绿红合法状态、防重叠、地面射线 `BaseGround`、放置和存档基础。
- 以下类名仅为**拟定架构示例**，不能当作项目当前已有的源码类。

## 15.2 建议模块拆分

| 模块 | 职责 | 推荐落点 |
|---|---|---|
| DragonDefinitions | 静态物种、技能池、进化线、外观配置 | `UPrimaryDataAsset` / DataAsset |
| DragonInstanceData | 每只龙的 ID、血脉、词条、祖印、成长状态 | C++ 结构体 + 持久化 |
| DragonBreeding | 亲代校验、遗传随机种子、基因结算、生成龙蛋 | C++ 服务/子系统 |
| DragonGrowth | 孵化、成长、专精、觉醒、返祖 | C++ 数据逻辑 + 蓝图表现 |
| DragonCombat | 元素效果、攻击模块、遗传修饰、局内 Build | C++ 可复用组件 + 蓝图/Niagara |
| Companion/Mount | 跟随、目标指令、上下龙、控制权交换 | Character/Pawn + 组件/状态机 |
| RunDirector | 波次、遭遇、路线选择、BOSS、结算 | 扩展现有 Director/Definition |
| BaseBuilding | 200cm 占地、地面射线、移动、拆除、保存 | 复用既有蓝图与 C++ 逻辑 |
| DragonRosterUI | 龙列表、筛选、双亲预览、档案、家谱 | UMG/蓝图 |
| PersistentSave | 基地、龙、蛋、资源、进度、世界事件、版本 | SaveGame + 验证/迁移 |

避免让世界中的龙 Actor 成为唯一的基因真相源。**核心个体数据应与场景实例解耦**，这样未展示的几十条龙也能稳定存储、繁殖与编队。

## 15.3 关键跨模块事件

```text
繁殖确认 → DragonBreeding 生成并保存 EggInstance
孵化进度完成 → EggInstance 转 DragonInstance
选择主力龙 → 出战槽引用稳定 DragonID
进入冒险 → 从 DragonInstance 构造战斗配置
局内升级 → 只更改 RunBuild，不污染先天数据
冒险结算 → 提交持久奖励与孵化进度
返回基地 → 显示更新后的龙、蛋、资源、设施
```

重要边界：**不要把局内升级直接写回遗传词条数组；不要让 Actor 销毁删除永久龙数据；不要在读档时重新抽蛋。**

## 15.4 骑乘状态机建议

状态：`OnFoot`（并肩）→ `Mounting` → `Mounted` → `Dismounting` → `OnFoot`，异常时进入可恢复安全状态。单一权威对象分配输入归属；切换时同步 Rider 位置、碰撞、AI、镜头、动画、技能调用对象和 HUD。

对于暂无法提供正式龙模型的阶段，以占位龙进行全部控制流测试。

# 16. 开发路线、验收门槛与先后依赖

## 16.1 优先顺序

1. **战斗基线恢复**：已有敌人、远程弹丸、火冰风表现、升级暂停、结算和返回基地重复可靠。
2. **人龙协同原型**：龙跟随、自动基础攻击、指令、上龙下龙、骑乘移动闪避。
3. **龙族持久数据**：定义与实例分离、唯一 ID、物种数据、元素比例、四槽词条、SaveGame。
4. **最小繁殖孵化**：火龙 + 风龙 → 烈风龙，生成蛋时确定基因，孵化后可选为主力。
5. **后代战斗差异**：亲代与烈风龙的攻击玩法可区分；至少两种不同遗传与局内 Build。
6. **闭环联通**：冒险资源 → 基地繁殖 → 孵化 → 使用后代 → 再次冒险；无调试命令亦可完成。
7. **小范围试玩**：验证动机、手感、稳定性；通过后扩展 P1 内容。

## 16.2 原型验收门槛

| 门槛 | 明确验收条件 |
|---|---|
| 战斗 | 敌人伤害、弹丸可躲避、元素机制可见且生效、结算不重复 |
| 协同 | 并肩跟随与攻击可用；骑乘后输入只控制龙；下龙后恢复正常 |
| 遗传 | 亲代相同不意味着后代必同；结果可解释、边界比例正确、无凭空祖印 |
| 孵化 | 生成即锁定基因，多次存取不重抽；孵化可以推进并完成 |
| 战斗差异 | 火龙、风龙、烈风龙在功能上明显不同，两种烈风 Build 有不同战术 |
| 存档 | 退出重进仍保留建筑、龙 ID、父母关联、蛋、词条、资源和出战状态 |
| 完整循环 | 无调试命令完成至少两次“冒险—培育—再出战” |
| 可玩性 | 试玩者能说出想继续繁殖的具体理由，而非只说动画好看 |

## 16.3 不应并行制造的依赖风险

- **骑乘/控制权未稳**：暂缓巨龙、飞行、复杂骑乘特技。
- **基因持久化未稳**：暂缓双祖印、多代家谱、祖龙制作。
- **元素表现不清**：暂缓堆更多高阶元素反应和全屏技能特效。
- **单局战斗不好玩**：暂缓扩建六区和大规模事件系统。
- **第一条融合龙缺少实质差异**：优先调整战斗机制，而不是增加外观款式。

# 17. 关键测试用例（建议转为 QA 清单）

### TC-01：骑乘输入归属

**给定**守龙者与测试龙处于并肩模式。**当**按 F 骑乘。**则**玩家输入控制龙、骑手附着稳定、龙的跟随 AI 暂停、人类不再响应独立 WASD；下龙后恢复。

### TC-02：远程怪与骑乘闪避

**给定**紫色远程怪在 `L_Combat` 发射弹丸。**当**玩家骑乘龙冲刺。**则**命中与闪避判定一致，不出现骑手独立承受隐藏重复伤害。

### TC-03：固定蛋遗传

**给定**火龙和风龙完成繁殖。**当**生成龙蛋后存档、退出并再次进入。**则**蛋 ID、物种、血脉、四词条、变异和亲代 ID 均一致。

### TC-04：潜在元素与物种

**给定**跨三元素的亲代组合。**当**形成后代。**则**四元素合计为 100%，表现物种由前两显性规则稳定计算；潜在元素不自动解锁第三套技能。

### TC-05：祖印不得凭空出现

**给定**两亲代均没有天劫祖印。**当**进行大量正常繁殖。**则**后代不会从普通突变池生成天劫祖印。

### TC-06：双印来源合法

**给定**一位亲代有双天劫祖印而另一位没有。**当**繁殖。**则**单亲不能向同一后代贡献两份印记。

### TC-07：升级不污染遗传

**给定**烈风龙在冒险中获得“冲刺留火”。**当**退出或结算。**则**局内效果清除，龙的先天词条和后代继承候选不变。

### TC-08：建筑移动时的龙蛋安全

**给定**孵化巢装有龙蛋。**当**移动或拆除。**则**蛋进入安全位置/存储，进度与基因均保留。

### TC-09：失败保留永久资产

**给定**玩家骑乘一条携印风暴龙冒险失败。**则**龙、祖印、家谱、已生成蛋、基地建筑均不消失，奖励按失败规则结算一次。

### TC-10：两种模式完成首领战

**给定**相同 BOSS。**当**分别使用并肩和骑乘完成挑战。**则**均存在合理的输出和躲避机会，没有必须使用某一状态的隐形锁。

# 18. 风险、取舍与验证实验

| 风险 | 早期信号 | 应对 |
|---|---|---|
| 繁殖好看但不想重复 | 玩家看一次孵化后不再主动配对 | 后代战斗差异、目标可追踪、减少随机折磨 |
| 骑乘只是换外观 | 玩家不觉得操控对象改变 | 改进龙攻击、冲刺、动画和相机，强化直接操控感 |
| 人龙双模式维护过重 | 大量技能在并肩和骑乘间不兼容 | 一份技能逻辑、两套释放/寻位适配 |
| 遗传系统过复杂 | 新手依赖外部攻略才能理解基础配对 | 预览概率/来源、简化显性规则、分期开放 |
| 强词条引发数值失控 | 无限弹射、分裂、频繁生成 Actor | 触发次数上限、性能预算、压力测试 |
| 基地沦为劳务管理 | 玩家每次出发前都需重复收菜 | 便利性优先、自动化、少量实体展示 |
| 内容承诺过量 | 六区/十龙/P2 先于第一条闭环 | 严守 P0/P1/P2 门槛 |
| 祖龙使普通龙失业 | 所有玩家只用祖龙 | 独特机制而非绝对数值碾压，保留普通龙 Build 空间 |
| 过于依赖随机掉落 | 无法计划获得基础龙与祖印 | 关键初始血脉与祖印设置稳定来源 |
| 特效影响战斗读图 | 看不到远程弹丸/BOSS 提示 | 特效分层、透明度设置、视觉优先级 |

**推荐首轮最重要的用户研究问题**：

1. 玩家能否在不看文字说明的情况下辨认火龙、风龙、烈风龙的战斗差异？
2. 玩家第一次孵出烈风龙并出战后，是否会主动提出第二个繁殖目标？
3. 玩家更愿意长时间骑乘，还是经常切换并肩？原因是什么？
4. 玩家读得懂繁殖结果为何出现吗？
5. 玩家回基地后，是期待管理新龙，还是觉得被大量操作阻碍下一局？

P0 仅在以下条件**同时满足**时才视为完成：

- [ ] 现有战斗稳定，火/冰/风至少两种在 P0 场景能明确显示且生效；远程弹丸、升级、结算正常。
- [ ] 守龙者和龙同屏并肩；龙能跟随和自动基础攻击。
- [ ] 骑乘和下龙稳定，可以直接操控龙的移动、闪避与主要技能。
- [ ] 有火龙、风龙、烈风龙三套可区分的战斗行为（可暂用占位模型）。
- [ ] 龙的物种、元素比例、四词条槽、亲代 ID、唯一 ID 能可靠保存。
- [ ] 火龙与风龙能够繁殖出烈风龙蛋；蛋在生成时已锁定基因。
- [ ] 冒险可推进孵化；孵出的烈风龙可以作为主力出战。
- [ ] 至少两种局内 Build 与两种遗传配置产生可见、可玩的差异。
- [ ] 基地设施与龙/蛋资源在退出重进后不丢失、不重复结算。
- [ ] 不使用调试命令，也能完成“冒险→繁殖→孵化→后代出战→下一局”的完整过程。

## 20.3 GDD 定稿后的工作方式

**设计文档不再无限叠加新玩法。** 后续研发按照：

```text
挑选一个 P0 功能
→ 细化数据与接口
→ UE5 C++/蓝图实现
→ PIE 验收
→ 存档/失败回归测试
→ 小范围试玩反馈
→ 更新 GDD 变更记录
→ 进入下一功能
```

如果试玩验证推翻某个核心假设，记录原因与具体修改，而不是在开发过程中随意新增平行系统。

# 附录 A：术语表

| 术语 | 定义 |
|---|---|
| 物种 | 固定图鉴条目，决定基础身体和招牌战斗机制 |
| 血脉比例 | 火/冰/风/雷四元素总和为 100% 的遗传组成 |
| 显性元素 | 用于表现物种及主要攻击风格的元素 |
| 潜在元素 | 存在于基因中，但不提供完整独立技能组的低占比元素 |
| 遗传词条 | 四槽内的先天可继承能力、行为与取舍 |
| 后天经历 | 某条龙在冒险中获得的个人历史，默认不遗传 |
| 常规进化 | 同物种内的永久战斗专精与表现变化 |
| 远古觉醒 | 不改变物种 ID 的古老形态/专属能力 |
| 真正返祖 | 满足祖脉要求并通过试炼，变更为固定古龙物种 |
| 祖印 | 独立于四词条的古老遗传标记，每亲代最多向同一后代贡献对应祖印一份 |
| 局内 Build | 仅当前肉鸽有效的技能强化组合 |
| 战场残留核心 | 仅作用于本场战斗的临时元素生态对象，非永久建造资源 |
| 安全撤退 | 在规定节点放弃后续挑战，按规则保留部分战利品 |
| 关键世界记录 | 玩家行为对未来产生可辨认影响的少量持久状态 |
